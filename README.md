## Projects

1. **[Shopify-Headless](https://github.com/PavankumarKokane/Shopify-Headless)**  
   Shopify-Headless is a modern headless e-commerce storefront built with React and Vite that connects to Shopify using GraphQL APIs to fetch product, collection, search, cart and checkout data, styled with Tailwind CSS and managing cart state through the React Context API to deliver a fast, customizable shopping experience completely decoupled from Shopify’s traditional theme system.

2. **[Node-MongoDB](https://github.com/PavankumarKokane/Node-MongoDB)**  
   Node-MongoDB is a backend API project built with Node.js, Express, and MongoDB using TypeScript, designed to handle CRUD operations for employee data with secure JWT authentication. It connects to a MongoDB database through Mongoose as the ODM (Object Data Modeling) library, organizes routes/controllers/models in a modular structure, and uses environment variables (dotenv) for configuration, showcasing a real-world REST API implementation for managing employee records and authentication in a scalable TypeScript backend.

3. **[Shopify-Gulp](https://github.com/PavankumarKokane/Shopify-Gulp)**  
   Shopify-Gulp in this repository is a Shopify theme development workflow setup that uses Gulp.js — a JavaScript-based build tool — to automate and enhance tasks like compiling SCSS, processing JavaScript, watching files and syncing theme changes with a Shopify store during development. By combining Shopify’s theme tooling with Gulp tasks (e.g., for styles, scripts, image handling and live reload), this project helps streamline local theme edits without manually uploading every change, demonstrating how to integrate a modern frontend workflow with a Shopify storefront using Node-based automation.

4. **[Elementor-Widgets](https://github.com/PavankumarKokane/Elementor-Widgets)**  
   Elementor‑Widgets is a simple WordPress plugin that bundles a set of custom Elementor widgets designed to extend the default Elementor page builder with additional functionality and design options. It includes various widget files and assets, integrates seamlessly with Elementor, is lightweight and developer‑friendly, and can be installed into a WordPress site by placing it in the wp‑content/plugins/ directory and activating it.

5. **[Book-Store](https://github.com/PavankumarKokane/Book-Store)**  
   Book-Store is a React-based web application that lets users search for and browse books by fetching data from the Google Books API, built with Vite for fast development and performance, styled using SCSS, and using the React Context API for state management. It includes custom React hooks to fetch both lists of books and individual book details, offers search capability, lazy loading for book lists, and a polished UI with loading skeletons

6. **[Postal-Info](https://github.com/PavankumarKokane/Postal-Info)**  
   Postal-Info is a simple React web application built with Vite that lets users search and view Indian postal information by consuming the Indian Post API (which returns details like area, district, and state for a given PIN code). The frontend uses React for UI and includes react-loading-skeleton to show placeholder loading screens while fetching data, demonstrating a modern, responsive tool for retrieving postal lookup details using live API calls in a fast development setup.

7. **[WordPress-Headless-Blogs](https://github.com/PavankumarKokane/WordPress-Headless-Blogs)**  
   WordPress-Headless-Blogs is a modern headless blogging project that uses WordPress as a backend content management system while delivering the frontend through a separate JavaScript application built with Vite and styled using Tailwind CSS. Instead of relying on traditional WordPress themes, the project fetches blog content via the WordPress REST API and renders it in a fast, decoupled frontend environment, demonstrating how to build a scalable and performance-optimized blog architecture.

8. **[Health-Stripe](https://github.com/PavankumarKokane/Health-Stripe)**  
   Health‑Stripe is a React.js web application that showcases various health plans and allows users to securely select and subscribe to them using Stripe for payment processing through the @stripe/stripe-js library. It demonstrates a modern frontend setup with smooth user interactions, secure payment integration, and a clean UI for managing and subscribing to health plans.
